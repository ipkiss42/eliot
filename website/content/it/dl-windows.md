## Eliot 2.1 {#versione-21}

Il pacchetto per Windows contiene Eliot 2.1, originariamente distribuito per Windows 2000 e versioni successive. È un archivio ZIP; non serve un programma di installazione.

1. Scaricate [eliot-2.1-win32.zip](https://dl.sv.nongnu.org/releases/eliot/releases/2.1/eliot-2.1-win32.zip).
2. Estraete **l’intero archivio** in una cartella a vostra scelta.
3. Aprite la cartella `eliot-2.1` estratta e avviate **`eliot.exe`**. Conservate gli altri file accanto all’eseguibile.

## Codice sorgente

Per compilare Eliot, consultate il [codice sorgente e le istruzioni di compilazione](/it/dl-sources/).

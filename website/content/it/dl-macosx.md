## Pacchetto Mac OS X

Il seguente pacchetto pre-compilato gira su Mac OS X 10.6 o versioni successive:

- [eliot-2.1.dmg](http://dl.sv.nongnu.org/releases/eliot/releases/2.1/eliot-2.1.dmg)

Per Mac OS X 10.4 e 10.5, si può usare ancora [Eliot 1.12](http://dl.sv.nongnu.org/releases/eliot/releases/1.12/eliot-1.12.dmg).

## Installazione

Eliot per Mac OS X è distribuito come immagine disco (.dmg). Per installarlo, è sufficiente aprire il file e copiare Eliot sul disco rigido (ad esempio nella cartella `/Applications`).

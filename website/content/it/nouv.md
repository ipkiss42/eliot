## 14 ottobre 2012: Eliot 2.0 {#14-ottobre-2012-eliot-20}

Questa versione introduce molte nuove funzionalità.{{< br >}}

Tra le novità principali:

- Nuova modalità arbitrato:
  - mossa master scelta dall'arbitro, o automaticamente
  - modo estremamente efficace per assegnare mosse ai giocatori (pochi tasti o clic del mouse, scorciatoie intelligenti)
  - possibilità di continuare a giocare, anche se un turno è incompleto
  - possibilità di aggiungere un giocatore durante il gioco, o di cambiare il suo numero di tavolo
  - possibilità di assegnare la stessa parola a molti giocatori con un solo clic
  - possibilità di dare assoli, avvertimenti e sanzioni per i giocatori
  - messaggi di conferma, per evitare gli errori arbitrali comuni (possono essere disattivati)
- Nuova vista *Statistiche*: tutte le informazioni sul gioco in un colpo d'occhio
- Nuovo aspetto delle lettere del sacchetto, molto più grafico e intuitivo
- Nuovo "timer", per giocare con limiti di tempo
- Giocatori preferiti: non c'è bisogno di creare gli stessi giocatori ogni volta
- Salvataggio automatico: la partita corrente viene salvata automaticamente (utile in caso di crash)
- Forma di salvataggio più completa
- Miglioramenti ergonomici generali
  - barra di stato più completa (cambia numero, lettere residue)
  - gestione messa a fuoco più intuitiva
  - meno spazio perduto
- Nuova traduzione dell'interfaccia in spagnolo
- Molte correzioni di bug

Nota: a causa dei grossi cambiamenti interni, i salvataggi di partite create con una versione precedente di Eliot non sono compatibili con questa nuova versione.

## 18 ottobre 2008: Eliot 1.7a {#october-18-2008-eliot-17a}

This version corrects a pretty annoying bug, which was introduced in the previous version: the search could miss some solutions when the rack contained a joker. Thanks to Christian Pierre for detecting the problem.

## 27 settembre 2008: Eliot 1.7 {#september-27-2008-eliot-17}

There are two main novelties in this new version:

- The graphical user interface has been entirely rewritten, and should be more intuitive. The older one is still available, but it will probably disappear in the next version of Eliot. If you think that something is missing in the new interface, please tell us!
- Three different types of game are now available:
  - Training mode: the mode already present in the previous versions of Eliot
  - Duplicate mode: a multiplayer game (with human or computer players), in which all the players have the same rack
  - Classic mode: this is the classical Scrabble game, in which the players take turns

It is also possible to play joker games.

Note: for now, saving games is only possible in the training mode.

## 1 marzo 2003: Eliot 1.3 {#1-mars-2003-eliot-13}

Merci beaucoup à Olivier Teulière pour les nombreuses corrections sur le code d'Eliot.

- effacement de résultats de recherche lors du chargement d'une partie

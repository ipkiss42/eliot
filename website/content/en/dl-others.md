For operating systems without a package listed on this site, you will need to build Eliot from source.

1. Get the [source code](/en/dl-sources/), choosing either the Eliot 2.2 release archive or the development version.
2. Follow the `INSTALL` file included with that version to install its dependencies and build Eliot.
3. Return to the installation guide to choose a dictionary and start a game.

If you know of a precompiled package for another system, [tell us on the eliot-dev email list](/en/help/#eliot-dev) so we can add a link.

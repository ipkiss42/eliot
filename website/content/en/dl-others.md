For the other supported operating systems, there is no precompiled binary.{{< br >}} You need to download the [source code](/en/dl-sources/) and to build it yourself.

Note: if you know how to find compiled versions of Eliot for another operating system, please [contact us](/en/contact/), so we can add a link.

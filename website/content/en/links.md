## Technical links

- Access to the [Eliot project on GitHub](https://github.com/ipkiss42/eliot)
- [News archive](/en/news/)
- Access to the [Eliot project on Ohloh](http://www.ohloh.net/p/eliot)
- [DAWG dictionary format](http://www.wutka.com/dawg.html): the format used for Eliot dictionaries
- [The World's Fastest Scrabble Program](/download/aj.pdf): search algorithm used in Eliot (by Andrew W. Appel and Guy J. Jacobson)
- [A Faster Scrabble Move Generation Algorithm](http://www.ericsink.com/downloads/faster-scrabble-gordon.pdf): an improvement of the previous algorithm (by Steven A. Gordon)
- [Qt library](http://trolltech.com/products/qt/): used in Eliot for the graphical user interface

## Scrabble

- [Zyzzyva](http://zyzzyva.net/): a free and powerful word study program. Supports several dictionaries.
- [Internet Scrabble Club](http://www.isc.ro/): a free site to play Scrabble online; various dictionaries are available (for English, French, Italian, Romanian and Dutch)
- [Quackle](http://web.mit.edu/jasonkb/www/quackle/): a Scrabble program specialized in analysing games (classic mode)
- [Lampword](http://members.shaw.ca/lampwords/): a Scrabble game for PalmPilot by Paul Sidorsky (in French)
- [Montpellier Scrabble club](http://www.montpellier-scrabble.org/) (in French)
- [Patrick Jenty's pages](http://patrick.jenty.free.fr/) (in French)

## Eliot 2.1

Latest release: [eliot-2.2.tar.gz](http://dl.sv.nongnu.org/releases/eliot/releases/2.2/eliot-2.2.tar.gz){{< br >}} The build instructions are detailed in the INSTALL file, provided with the source code. If you have problems compiling the program, you can ask for help on the eliot-dev mailing-list (see the [Contact](/en/contact/) section).

## Development version

The development version is available via git. To get it, you can use the following command:

- `git clone https://github.com/ipkiss42/eliot.git`

## Older versions

You can download older versions of Eliot on [Savannah](http://dl.sv.nongnu.org/releases/eliot/releases/).

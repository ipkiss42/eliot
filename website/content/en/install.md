To use Eliot, you need **both the software and a dictionary**. Install the program, download a dictionary for your playing language, then select it in Eliot.

## 1. Install Eliot {#download-eliot-version-21-or-22-depending-on-the-platform}

Choose your operating system for installation instructions:

- **[Windows](/en/dl-windows/)** — Eliot 2.1, ZIP archive to extract.
- **[Debian/Ubuntu](/en/dl-debian/)** — packages for older Ubuntu releases and source-build dependencies.
- **[Mac OS X](/en/dl-macosx/)** — Eliot 2.1, DMG disk image.

For other systems or a custom build, see [other operating systems](/en/dl-others/) and the [source code](/en/dl-sources/) (Eliot 2.2 release archive and development version).

[Release notes on GitHub](https://github.com/ipkiss42/eliot/releases)

## 2. Choose a dictionary {#download-a-dictionary}

[Download a dictionary](/en/dict/) for the language you want to play in. Save the `.dawg` file in a folder where you can keep it and find it again.

Dictionary languages are independent of the website language and Eliot's interface language. You can also [create a dictionary from your own word list](/en/dict/#own).

## 3. Start a game {#first-launch}

1. Open Eliot.
2. Choose **Settings → Choose dictionary...** and open the `.dawg` file you downloaded.
3. Choose **Game → New...**, select a game mode, set up the players if needed, and confirm with **OK**.

Keep the dictionary file in its chosen folder so Eliot can find it next time. Use **Settings → Choose dictionary...** again whenever you want to switch dictionaries.

If you need help installing Eliot or loading a dictionary, [ask the eliot-dev email list](/en/help/#eliot-dev).

## Mac OS X package

The disk image offered here contains Eliot 2.1, originally provided for Mac OS X 10.6 and later.

- [Download eliot-2.1.dmg](https://dl.sv.nongnu.org/releases/eliot/releases/2.1/eliot-2.1.dmg)

## Installation

1. Open the downloaded `.dmg` disk image.
2. Copy **Eliot** to your **Applications** folder (`/Applications`).
3. Open Eliot from Applications.

## Source code

To build Eliot yourself, see the [source code and build instructions](/en/dl-sources/).

## Older versions

The historical package for Mac OS X 10.4 and 10.5 is [Eliot 1.12](http://dl.sv.nongnu.org/releases/eliot/releases/1.12/eliot-1.12.dmg).

## Mac OS X package

The precompiled package below works on Mac OS X 10.6 or later:

- [eliot-2.1.dmg](http://dl.sv.nongnu.org/releases/eliot/releases/2.1/eliot-2.1.dmg)

For Mac OS X 10.4 and 10.5, you can still use [Eliot 1.12](http://dl.sv.nongnu.org/releases/eliot/releases/1.12/eliot-1.12.dmg).

## Installation

Eliot for Mac OS X is distributed as a disk image (`.dmg`). To install it, you only need to open the file and to copy Eliot to your hard drive (for instance in the `/Applications` folder).

If you want, you can download the [source code](/en/dl-sources/) of Eliot.

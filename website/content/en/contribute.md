## Programmers

Eliot has been developed by Antoine Fraboulet and Olivier Teulière. New developers are welcome.

There are still many things to do to improve Eliot. Here are some examples:

- network game, to play with friends through Internet
- improvement of the artificial intelligence in the classic mode
- implementation of the [GADDAG](http://www.ericsink.com/downloads/faster-scrabble-gordon.pdf) dictionary format for an even faster search
- ...

## Non-programmers

Even if you don't know how to program or simply don't want to, there are still many other ways to participate in the project:

- help promoting Eliot (Scrabble club, websites, friends, ...)
- translate Eliot into another language
- write a small user guide or a tutorial
- provide the official word list in a language other than French or English
- report bugs in the program
- ... and any other ideas that could help improve the program (suggestions about the ergonomics, ...)

Feel free to [contact us](/en/help/) about it!

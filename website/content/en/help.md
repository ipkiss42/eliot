## Installation and dictionaries

Start with the [installation instructions](/en/install/) for your operating system and [choose a dictionary](/en/dict/) for your playing language.

For installation, dictionary, or startup problems, use the [eliot-general email list](#eliot-general). For help compiling from source, use [eliot-dev](#eliot-dev).

## Report a bug

You can report a bug by emailing [eliot-general@nongnu.org](mailto:eliot-general@nongnu.org). No GitHub account is needed.

If you prefer GitHub, [search existing issues](https://github.com/ipkiss42/eliot/issues) before [opening a bug report](https://github.com/ipkiss42/eliot/issues/new).

Whichever method you choose, please include:

- Your operating system and its version
- Your Eliot version and how you installed it
- The steps to reproduce the problem, what you expected, and what happened
- The complete error message, if any, and a screenshot if it helps explain the problem

## Email lists

There are two separate email lists, for different kinds of questions:

### eliot-general — installation, usage, and bugs {#eliot-general}

For installation help, dictionary and usage questions, bug reports, suggestions, or general discussion, email [eliot-general@nongnu.org](mailto:eliot-general@nongnu.org). Messages from non-subscribers may need moderator approval.

The [eliot-general information page](https://lists.nongnu.org/mailman/listinfo/eliot-general) provides subscription settings and a link to the archives.

### eliot-dev — building from source and development {#eliot-dev}

For help compiling Eliot from source or for development discussions, email [eliot-dev@nongnu.org](mailto:eliot-dev@nongnu.org). Include your operating system, Eliot version, build commands, and the complete error message.

The [eliot-dev information page](https://lists.nongnu.org/mailman/listinfo/eliot-dev) provides subscription settings and a link to the archives. See also the [source code and build instructions](/en/dl-sources/) and [ways to contribute](/en/contribute/).

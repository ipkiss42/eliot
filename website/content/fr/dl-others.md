Pour les autres systèmes d'exploitation supportés, il n'y a pas de binaires pré-compilés.{{< br >}} Vous devez télécharger le [code source](/fr/dl-sources/) et le compiler vous-même.

Note : si vous savez comment obtenir des versions compilées d'Eliot pour un autre système d'exploitation, merci de [nous contacter](/fr/contact/), pour pouvoir mettre à jour cette page.

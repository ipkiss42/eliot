title: Installer Eliot sur un autre système d’exploitation
aliases:

Pour les autres systèmes d'exploitation supportés, il n'y a pas de binaires précompilés.{{< br >}} Vous devez télécharger le [code source](/fr/dl-sources/) et le compiler vous-même.

Note : si vous savez comment obtenir des versions compilées d'Eliot pour un autre système d'exploitation, merci de [nous contacter](/fr/help/), pour pouvoir mettre à jour cette page.

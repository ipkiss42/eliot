Pour les systèmes d’exploitation sans paquet proposé sur ce site, il faut compiler Eliot à partir du code source.

1. Récupérez le [code source](/fr/dl-sources/), en choisissant l’archive d’Eliot 2.2 ou la version de développement.
2. Suivez le fichier `INSTALL` fourni avec cette version pour installer ses dépendances et compiler Eliot.
3. Revenez au guide d’installation pour choisir un dictionnaire et démarrer une partie.

Si vous connaissez un paquet précompilé pour un autre système, [signalez-le à la liste de discussion eliot-dev](/fr/help/#eliot-dev) pour que nous puissions ajouter un lien.

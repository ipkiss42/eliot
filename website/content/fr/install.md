Pour utiliser Eliot, il vous faut **le programme et un dictionnaire**. Installez le programme, téléchargez un dictionnaire pour votre langue de jeu, puis sélectionnez-le dans Eliot.

## 1. Installer Eliot {#télécharger-eliot-version-21-ou-22-selon-la-plateforme}

Choisissez votre système d’exploitation pour suivre les instructions d’installation :

- **[Windows](/fr/dl-windows/)** — Eliot 2.1, archive ZIP à décompresser.
- **[Debian/Ubuntu](/fr/dl-debian/)** — paquets pour d’anciennes versions d’Ubuntu et dépendances de compilation.
- **[Mac OS X](/fr/dl-macosx/)** — Eliot 2.1, image disque DMG.

Pour les autres systèmes ou une compilation personnalisée, consultez les [instructions de compilation à partir des sources](/fr/dl-sources/) (archive d’Eliot 2.2 et version de développement).

[Notes de version sur GitHub](https://github.com/ipkiss42/eliot/releases)

## 2. Choisir un dictionnaire {#télécharger-un-dictionnaire}

[Téléchargez un dictionnaire](/fr/dict/) pour la langue dans laquelle vous souhaitez jouer. Enregistrez le fichier `.dawg` dans un dossier où vous pourrez le conserver et le retrouver.

Les langues des dictionnaires sont indépendantes de la langue du site et de celle de l’interface d’Eliot. Vous pouvez aussi [créer un dictionnaire à partir de votre propre liste de mots](/fr/dict/#own).

## 3. Démarrer une partie {#first-launch}

1. Ouvrez Eliot.
2. Dans **Paramètres → Choisir un dictionnaire...**, ouvrez le fichier `.dawg` téléchargé.
3. Dans **Partie → Nouvelle partie...**, choisissez un mode de jeu, configurez les joueurs si nécessaire, puis validez avec **OK**.

Conservez le dictionnaire dans le dossier choisi pour qu’Eliot puisse le retrouver au prochain démarrage. Pour changer de dictionnaire, utilisez à nouveau **Paramètres → Choisir un dictionnaire...**.

Si vous avez besoin d’aide pour installer Eliot ou charger un dictionnaire, [écrivez à la liste de discussion eliot-general](/fr/help/#eliot-general).

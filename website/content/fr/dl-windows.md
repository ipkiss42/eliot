## Version 2.1

Cette version d'Eliot fonctionne sur toutes les versions de Windows à partir de Windows 2000.{{< br >}} Aucune installation n'est nécessaire, il suffit de décompresser le fichier dans un répertoire.

- [eliot-2.1-win32.zip](http://dl.sv.nongnu.org/releases/eliot/releases/2.1/eliot-2.1-win32.zip)

modes:
- Le mode **partie libre** est le mode traditionnel, l'idéal pour s'amuser en famille. Les joueurs possèdent
  chacun leur tirage et jouent à tour de rôle.
- Le mode **duplicate** est la façon privilégiée de jouer en club et en compétition. Dans ce mode, les
  joueurs réfléchissent en même temps sur le même tirage et la même grille. Il élimine ainsi la part de
  chance (et de tactique).
- Le mode **entraînement** permet de jouer seul et de progresser au duplicate. Il offre plus de liberté
  que les modes multi-joueurs.
- Le mode **arbitrage** permet d'arbitrer de manière très efficace une partie duplicate, potentiellement
  avec un grand nombre de joueurs.

## Jeu de Scrabble gratuit

Eliot est un jeu de Scrabble [open source](http://fr.wikipedia.org/wiki/Open_Source), disponible librement sous la [licence publique générale GNU (GPL), version 2 ou ultérieure](https://github.com/ipkiss42/eliot/blob/main/COPYING).

Eliot propose également de nombreuses fonctions de **recherche** avancées. Vous pouvez ainsi :

- Chercher le meilleur coup pour une grille et un tirage donnés. La recherche est quasi-instantanée !
- Chercher des raccords sur un coup, des benjamins ou des mots composables avec les lettres du tirage.
- Un module de recherche dans le dictionnaire par [expressions régulières](http://fr.wikipedia.org/wiki/Expression_r%C3%A9guli%C3%A8re) est également disponible.
